# AI Memory
Persistent, agent-readable context for PromptUI.

## Layout
- project-overview.md — high-level context
- codex-guidelines.md — repo-specific coding/testing/PR rules
- checklists/ — agent-readable checklists
- prompts/ — reusable prompt templates
- pitfalls.md — recurring issues to avoid
- index.yaml — lightweight manifest for agent discovery

## Usage
Agents should read project-overview + their role-specific files (see AGENTS.md).
