# Project Overview (PromptUI)
Purpose: High-level context for all agents.

## Goals
- Demonstrate PromptUI core and example libraries (Angular, etc.)
- Establish AI/agent-friendly conventions (memory, prompts, checklists)

## Modules (examples)
- examples/angular-library — Angular library example (tests via jest-preset-angular)
- memory/ — persistent AI context (directives, prompts, checklists)

## Conventions (quick)
- Package manager: pnpm
- Scripts: install `pnpm i`; lint `pnpm lint`; tests `pnpm test`, Angular: `pnpm test:angular-lib`
- Commits: Conventional Commits
